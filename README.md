# 参星（Trinary）

> 基于天文隐喻的知识图谱系统

## 项目简介

参星是一个基于天文隐喻的知识图谱系统，用星云、恒星、星团、旋臂、宇宙网等天文结构来组织知识，让知识的组织方式本身成为知识的一部分。

## 核心概念

### 天文隐喻

| 天文概念 | 知识图谱概念 | 核心含义 |
|----------|------------|----------|
| 星云 | 知识原料池 | 原始想法、未验证信息、灵感碎片 |
| 恒星 | 知识单元 | 一个独立的、已凝聚的知识点 |
| 行星 | 派生知识 | 从核心知识延伸出的子知识点 |
| 卫星 | 细节知识 | 支撑派生知识的具体细节 |
| 星团 | 知识聚类 | 多个恒星系统的聚合 |
| 旋臂 | 知识密度路径 | 由关联密度自动涌现的主干路径 |
| 超新星 | 洞察爆发 | 项目结束后散落的高价值洞察 |

### 两个正交维度

- **生命周期**（成熟度）：原恒星 → 主序星 → 红巨星 → 白矮星 / 超新星
- **知识层次**（内容性质）：事实 / 决策 / 洞察 / 约束

### 知识循环

```
星云 → 原恒星 → 主序星 → 红巨星 → 超新星 → 回归星云
```

## 技术栈

- **后端**: Python + FastAPI
- **数据库**: SQLite（初期）→ PostgreSQL（后期）
- **前端**: React + PixiJS
- **AI 模型**: MiMo-V2-Flash + MiMo-V2.5-Pro + DeepSeek-V3.2

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/your-username/trinary.git
cd trinary
```

### 2. 启动后端

```bash
cd backend

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 3. 启动前端

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 4. 访问应用

打开浏览器访问 http://localhost:5173

## API 文档

启动后端后，访问 http://localhost:8000/docs 查看 API 文档

## 设计理念

- **知识决定输出质量**：AI 执行的正确性完全取决于它拥有的知识质量
- **知识是循环的**：超新星散落的洞察滋养下一代恒星
- **人类识别模式，AI 执行模式**：人类发现规律，AI 遵循规则
- **失败编码为规则**：每次失败 = 1 条新规则，系统永远不会以同样方式失败两次
